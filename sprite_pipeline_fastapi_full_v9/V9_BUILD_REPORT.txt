Sprite Pipeline V9 build report
================================

Version: 9.0.0
Build status: staging candidate
Build date: 2026-08-22

Purpose
-------
V9 does not replace the working V8 human/character path. It separates animal
requests from the human-only motion assumptions that caused quadruped and
biped-animal failures.

Routing matrix
--------------
character      -> kimodo            -> V8 human adapter  -> One-to-All -> V8 QC
quadruped      -> animal_procedural -> V9 animal adapter -> One-to-All -> animal QC
quadruped      -> animal_npz        -> V9 animal adapter -> One-to-All -> animal QC
biped_animal   -> animal_procedural -> V9 animal adapter -> One-to-All -> animal QC
biped_animal   -> animal_npz        -> V9 animal adapter -> One-to-All -> animal QC

The API accepts subject_profile and motion_backend independently. Invalid
human/animal backend combinations are rejected before queue and job-directory
creation. Kimodo availability gates only character jobs; animal jobs require
One-to-All but do not require Kimodo.

Upstream source audit
---------------------
1. One-to-All infer_utils.py loads YOLOv10m and ViTPose whole-body, converts
   detections to DWPose, and performs human reference/driving alignment.
2. One-to-All infer_preprocess.py builds pose/control inputs around that
   human-pose preprocessing contract.
3. Kimodo's official scope is human/humanoid kinematic motion generation.

V9 therefore preserves those components for character requests and bypasses
Kimodo plus human reference-pose detection/alignment for animal requests.
The animal branch still uses One-to-All as the renderer; it is not represented
as a newly trained animal diffusion model.

Release decision
----------------
This package is a valid V9 staging candidate, not a production-confirmed animal
pipeline. Production promotion requires retained successful L40S results for
representative quadruped, biped-animal,
and external-NPZ jobs. The routing isolation and failure handling are tested;
new animal diffusion output quality is not claimed without those GPU runs.
