Sprite Pipeline V8 Build Report
Date: 2026-08-20
Version: 8.0.0

Purpose
-------
V8 preserves the V6 cardinal-heading correction and the V7 exact cyclic-control
pipeline. It adds two production gates after One-to-All rendering:

1. Shared four-view reference-palette appearance stabilization.
2. Native-resolution 8->1 foreground geometry and color closure validation.

Implemented components
----------------------
- server/app/image_features.py
  Border-derived foreground masks, native foreground geometry, CIE Lab conversion.
- server/app/appearance_postprocess.py
  Four-view deterministic Lab palette, per-frame palette pull, weak luminance and
  contrast correction, temporal Lab alignment, appearance QC reports.
- server/app/loop_postprocess.py
  Existing phase candidate selection plus centroid, ground line, body height,
  foreground area, and color seam metrics.
- server/app/pipeline.py
  Appearance stage before loop selection, combined acceptance/retry, V8 metadata.
- workers/ota_worker.py
  V8 version and extra negative-prompt terms for palette/lighting flicker; V7
  translation-only pose stabilization remains unchanged.
- Adapter and Kimodo worker versions promoted to 8.0.0 without changing the
  validated V7 gait/cycle/cardinal behavior.

Offline backtest using attached V7 outputs
------------------------------------------
Method: the attached final V7 eight-frame outputs were duplicated into 16 temporal
slots and phase zero was copied into slot 16. The actual final V8 package modules
were then run against those reconstructed inputs. This tests the final V8
appearance and decision code, but does not replace a new 17-frame GPU render.

Appearance stabilization:
- Shopkeeper: appearance QC passed. Mean direction-level temporal chroma spread
  changed from 5.076 to 3.296; temporal luma spread from 2.996 to 1.913.
- Short traveler: appearance QC passed. Mean temporal chroma spread changed from
  2.399 to 1.374; temporal luma spread from 4.874 to 4.299.
- Blacksmith: appearance QC passed. Mean temporal chroma spread changed from
  2.094 to 1.633; temporal luma spread from 4.282 to 3.648.
- Mean foreground correction remained limited: approximately 1.04-3.66 deltaE
  across the three assets.

V8 loop gate after appearance processing:
- Shopkeeper: passed; selected even_end.
- Short traveler: rejected; selected even_end but front 8->1 centroid ratio
  0.01639 and ground ratio 0.015625 exceeded the V8 0.011 defaults.
- Blacksmith: passed; selected even_end.

This reproduces the intended production decision: the previously observed
front-view boundary jump is sent to another One-to-All seed while stable samples
remain accepted. Full values are stored in V8_BACKTEST_SUMMARY.json.
